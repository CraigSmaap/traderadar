TradeRadar — Trade Strategy GuideS-3 · Filter Gates
Hard Filter System

5 Hard Filter Gates — All Must Pass

A signal is blocked if any filter fails. These gates run before RadarScore is calculated, preventing low-quality entries from reaching the score engine.

Filter 1 · EMA-50 Trend Alignment
Price must be above EMA-50 on H1 for BUY signals. Price must be below EMA-50 on H1 for SELL signals. Counter-trend trades are blocked entirely.
Filter 2 · RSI Guardrails
BUY: RSI must be between 50 and 72 (not overbought). SELL: RSI must be between 28 and 50 (not oversold). Extreme readings block entry.
Filter 3 · Directional Bias
H4 and H1 timeframes must agree on direction. Conflicting multi-timeframe bias causes the signal to be suppressed until alignment is confirmed.
Filter 4 · Entry Zone Validity
Current price must be within 1.5% of the calculated entry zone. If price has moved beyond the zone, the signal is invalid and will not fire.
Filter 5 · Minimum Confidence Level
Signal confidence must be MEDIUM or above. LOW confidence signals are suppressed system-wide. Gold requires HIGH or VERY_HIGH confidence — MEDIUM is blocked for XAUUSD.

8-Step MT5 Trade Execution Guide (Exness)

1
Open TradeRadar Signal
Tap the signal card to expand. Note Entry, SL, TP1, TP2, TP3 values and RR ratio.
2
Calculate Lot Size
Use the built-in lot calculator: enter account balance, risk %, and SL pips to get the correct lot size.
3
Open MT5 — Find the Instrument
In MT5, open Market Watch. Search the symbol (e.g., EURUSDm or XAUUSDm for Exness micro accounts).
4
Tap New Order
Long press the symbol → New Order. Or tap Trade → New Order from the chart view.
5
Set Order Type
Select Market Execution for immediate entry, or Buy/Sell Limit to set a pending order at the entry price zone.
6
Enter Volume, SL and TP
Set Volume = calculated lot size. Set Stop Loss at signal SL level. Set Take Profit at TP1 first.
7
Confirm and Place Order
Review all values. Tap Buy/Sell to confirm. Order appears in Trades tab immediately.
8
Log in TradeRadar Journal
Immediately log the trade in TradeRadar: select the signal, enter lot size, tag emotional state.
